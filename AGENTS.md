## Cursor Cloud specific instructions

### Project overview

Kleopatra INK is a client-only React SPA (Vite + React 18) for a tattoo studio. There is no backend, no database, no API, and no environment variables required.

### Running the app

- `npm run dev` — starts Vite dev server on `http://localhost:5173`
- `npm run build` — production build to `dist/`
- `npm run preview` — preview production build

### Notes

- No ESLint or test framework is configured. There are no lint or test commands.
- The `project/` and `chats/` directories are design reference artifacts from the Claude Design handoff and are not part of the runtime application.
- The site is entirely in German.
